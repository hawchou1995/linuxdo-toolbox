## 收尾阻塞

初始配置备份放在任务标签 sessionStorage；长任务超过浏览器会话生命周期后，旧 Agent 标签被关闭，备份不再可取。此备份方式不足，后续真机验收必须在改配置前将**仅本任务配置键**另存本地受限 scratch，并明确恢复校验，不能只依赖标签生命周期。

Linux.do 从仍打开的旧版工具箱内存读取原七项开关并恢复，写后相等核验通过。青橘原标签无法提供可用基线，随后借用请求被拒绝，未重试或绕过；IDC Flare 没有可用原标签或仍存备份。因此两个站点的原开关恢复**无法准确证明**，没有用默认值冒充原状。两站仅清除确认属于本次的临时过滤规则，测试时写入的七项全关闭状态保留未猜改。

原借入标签已归还，新会话已停止；本次临时 daemon 使用受支持 stop 关闭，临时计划任务删除。最终 `Win32_Process` 核验 bsk 进程数为 0，计划任务查询退出码 1（任务不存在）。
