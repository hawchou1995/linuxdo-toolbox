# 本地屏蔽快捷按钮显示开关设计

**日期：** 2026-10-16
**状态：** 交互方案已获批准；待审阅本文规格

## 目标

允许在“内容过滤”子面板中隐藏头像下的“本地屏蔽”快捷按钮。默认保持显示，以维持升级前的行为。关闭快捷按钮只移除三个入口，不删除、停用或改变已有规则；内容过滤仍按原配置工作。

## 选定方案

在现有 `ContentFilter` 配置对象中增加布尔字段 `quickBlockButtons`，存于既有 `ldkit.contentFilter.v1` 本地配置。此字段不改变配置 `version: 1`：旧配置缺少字段时按 `true` 补默认值；若导入值不是布尔值，则按现有配置校验规则拒绝保存。

在“内容过滤”子面板增加“快捷入口”分区和“显示头像下的本地屏蔽按钮”开关。开关沿用既有配置保存机制，保存成功后立即执行按钮扫描；关闭时移除话题帖子、用户资料、用户卡片三个入口，重新开启后重新扫描并挂载当前页面入口。存储失败时保留旧配置和旧按钮状态，并在面板状态栏显示错误。

## 行为边界

- 默认值为 `true`；旧版已保存配置及缺少该字段的 JSON 导入继续显示快捷按钮。
- 关闭时只隐藏快捷入口。已保存的快速屏蔽规则仍可在规则列表中查看、编辑、停用或删除；启用中的规则仍正常折叠匹配内容。
- 内容过滤总开关、规则匹配、按钮对应的三个 DOM 位置、身份解析及站点忽略/静音设置均保持原样。
- 不增加按入口类型分别控制的选项。

## 组件与数据流

1. `scripts/content-filter.js`：默认配置加入 `quickBlockButtons: true`；校验并补齐旧配置；面板挂载开关；`scanQuickBlockButtons()` 在关闭态移除已挂载宿主并停止添加新按钮。
2. `linuxdo-toolbox.user.js`：通过现有 `scripts/build-content-filter.cjs` 构建同步嵌入模块，不另造一份逻辑。
3. `scripts/content-filter-selfcheck.html`：增加默认值、旧配置兼容、UI 切换/持久化、关闭不影响规则折叠、重开后入口恢复及保存失败回滚断言。
4. `docs/content-filter.md` 与 `README.md`：说明开关位置、默认值及“隐藏入口不关闭规则”的语义；版本记录与脚本内版本标记随实现同步。

## 验收标准

- 新默认配置和旧配置迁移后的 `quickBlockButtons` 均为 `true`。
- 关闭开关后，三个代表 DOM 均没有 `.ldkit-quickblock-host`；现存用户规则数量和状态不变，匹配内容仍按既有规则折叠。
- 重新开启并扫描后，当前页面符合条件的入口恢复，按钮状态仍反映原规则状态。
- 开关选择写入 `ldkit.contentFilter.v1`；刷新后保持选择；无效值或存储失败不造成配置与界面状态不一致。
- `node scripts/build-content-filter.cjs --check`、语法检查及 `node scripts/run-selfcheck.cjs` 全部通过。
