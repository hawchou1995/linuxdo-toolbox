# 快速本地屏蔽用户设计

**日期：** 2026-10-16  
**状态：** 已批准执行

## 目标

在话题帖子头像、用户 `/u/<username>/summary` 头像和用户卡片头像下提供一个「本地屏蔽 / 撤销屏蔽」按钮。按钮操作复用内容过滤模块的 `target: "user"` 规则，使该用户作为帖子作者或话题发起者时在本机折叠内容；不调用站点忽略/静音功能、不改账号设置、不删除帖子。

## 交互

- 按钮位于对应头像下方，使用 `button`、键盘可聚焦及 `aria-pressed`；显示态与同一用户的快速规则同步。
- 点击未屏蔽用户时，优先按数字 `userId` 精确匹配；DOM 不提供 ID 时按用户名 `author` 精确匹配。创建规则后若总开关关闭则自动开启。
- 再次点击快速屏蔽中的用户会移除该快速规则并恢复符合条件的原内容。若规则被面板停用，按钮显示未生效；点击重新启用。
- 点击失败（存储不可写、规则数量达到现有限额、身份缺失）不改变当前有效配置，并在内容过滤面板状态栏报告原因。
- 面板里手工创建的规则不被快速按钮暗中编辑或删除；快速规则在规则列表中可按现有方式编辑、停用和删除。

## 身份规则

- 帖子入口仅读取当前 `.topic-post` 作者身份，不读取回复者、引用或提及对象。
- 用户卡片入口仅读取当前卡片自身的用户身份；summary 入口的用户名可由 `/u/<username>/summary` 路由回退取得。
- `data-user-id` 存在且为数字字符串时作为主匹配条件；否则使用 `data-user-card` 或 `/u/<username>` 链接提取的用户名。昵称和头像 `alt` 不作为用户名来源。
- 快速规则保存稳定身份元信息，以便 ID 可用性不同的三个入口仍能识别同一条规则；过滤条件本身始终只用一个最精确可用身份字段。

## 页面挂载与生命周期

- 话题帖子头像宿主：`.topic-post .topic-avatar .post-avatar`，缺少该节点时回退到 `.topic-post .topic-avatar`。
- 用户卡片头像宿主：`.user-card .user-card-avatar`；兼容 `.user-card .avatar-wrapper` 与 `.user-card .avatar`。
- summary 页面仅在 `/u/<username>/summary` 路由处理 `.user-profile-avatar`，避免给其它页面头像误加按钮。
- 挂载采用带固定 data 标记的专属宿主，重复扫描幂等；复用内容过滤既有 MutationObserver 和周期扫描适配 SPA/异步卡片更新。规则保存、删除、跨页 storage 更新后同步所有可见按钮状态。
- 用户卡片内按钮阻止冒泡，避免点击时触发头像链接或关闭卡片。


## Linux.do DOM 实测（2026-10-16）

- 话题帖子实际使用 `.topic-post .topic-avatar .post-avatar`；作者身份可从头像区 `data-user-card` 与帖子树 `data-user-id` 取得。
- `/u/<username>/summary` 实际包含 `.user-profile-avatar`；头像节点没有用户 ID，路由用户名是有效回退来源。
- 用户卡片实际包含 `.user-card .user-card-avatar`，位于 `.user-card-avatar-wrapper` 内；头像区可从 `/u/<username>` 链接取得用户名，卡片 DOM 未提供 `data-user-id`。
- 登录态 DOM 只在 Linux.do 上核对；本任务不要求在其他 Discourse 论坛验收。
## 范围与约束

- 规则写入 `ldkit.contentFilter.v1` 的既有 `rules` 数组，服从现有 200 条总规则上限、字段校验、持久化和本地显示折叠/恢复机制。
- 总开关关闭时新增规则先保存成功再开启；保存失败不打开总开关。
- 不修改 `initOnlyUser` 的 Discourse 原生话题参与者筛选，不碰服务器数据、静音/忽略列表、阅读状态或发帖能力。
- 不扩大到列表头像、最近回复者、头像栏之外的其他用户链接。

## 验收

1. `ContentFilter` API 能为 ID 优先、用户名回退的身份新增、识别、撤销快速规则；保存失败不改存储。
2. 话题作者规则只命中作者帖子与话题发起者，不因提及或最近回复者命中。
3. 三种代表 DOM 都只在对应头像下生成一个按钮；重复扫描不重复挂载，新增/替换节点自动挂载。
4. 总开关关闭时首次屏蔽会先持久化规则并自动打开；撤销只移除该快速规则并恢复内容；按钮 `aria-pressed`、文本和标题同步。
5. 构建嵌入源码完全一致，内容过滤专项与原有自检通过。
6. 真实登录态页面验收三处入口。若借用浏览器守护进程不可用，单独标注为未完成的外部验收，不以离线 fixture 冒充。
